# .NET Web API Projects

A collection of ASP.NET Core Web API projects developed
to practice REST API development, database integration,
and backend application design.

## Projects

### 1. EcommerceAPI
A REST API for an ecommerce application.

- ASP.NET Core Web API
- C#
- Entity Framework Core
- SQL Server
- Product retrieval by ID and product listing
- Add-product endpoint

### 2. SuperHeroAPI
An ASP.NET Core Web API practice project focused on
building and working with REST endpoints.

## Getting Started

1. Install the .NET SDK required by each project.
2. Open the relevant `.csproj` file in Visual Studio.
3. Configure your own SQL Server connection string.
4. Apply the required database migrations or create the
   database according to the project setup.
5. Run the project and test its endpoints using Swagger,
   if configured.

## Notes

These projects are intended for learning and demonstration.
Local databases and machine-specific configuration are
not included.
