# LINQ Tutorial — Separate Files

This project reorganizes the concepts demonstrated in Nitish Kaushik's beginner LINQ playlist.
Each operator/example has its own class and `Run()` method, so no completed code needs to be deleted.

## Open in Visual Studio
1. Extract the ZIP.
2. Open `LinqTutorialSeparated.csproj`.
3. Press **Ctrl+F5**.
4. Select an example from the menu.

## Add another concept
1. Right-click the relevant folder in Solution Explorer.
2. Choose **Add > Class**.
3. Implement `ILinqExample`.
4. Add `new YourExample()` to the list in `Program.cs`.

Note: This is a clean, independently written reorganization matching the course concepts and behavior; it is not claimed to be a word-for-word transcript of copyrighted video code.
